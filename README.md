В этом репозитории собраны реализации различных методов многомерного статистического анализа.

Подробное описание файлов

1. PCA.py -- PCA на датасете Wine
Реализация PCA с нуля для визуализации и интерпретации данных о вине.
Что реализовано:
- Стандартизация признаков
- Нахождение собственных значений и векторов
- Проекция на первые 2 главные компоненты
- Визуализация с метками классов
- Интерпретация нагрузок

2. cca_comparison_classical_regularized_kernel.py -- Сравнение методов CCA
Сравнение трех подходов к каноническому корреляционному анализу.
Что реализовано:
- Classical CCA -- базовая реализация через 'sklearn'
- RCCA (Regularized CCA) -- ручная реализация с регуляризацией
- Kernel CCA -- ручная реализация с RBF ядром
- Сравнение с нелинейными признаками (hp^2, 1/mpg)

3. ellipse_analysis.py -- Эллипс рассеяния
Исследование свойства эллипса рассеяния для многомерных данных.
Что реализовано:
- Построение эллипса рассеяния по собственным значениям
- Вычисление расстояния Махаланобиса
- Сравнение нормального и равномерного распределений

4. mtcars_analysis_pca_bootstrap.py -- PCA + регрессия с бутстрепом
Анализ влияния стандартизации и выбросов на PCA + оценка надёжности R2.
PCA:
- Сравнение стандартизированных и нестандартизированных данных
- Влияние выброса на нагрузку PC1
- Визуализация нагрузок
Регрессия + бутстреп:
- Линейная регрессия 'mpg ~ wt + hp'
- Бутстреп (1000 итераций) для оценки доверительных интервалов R2

5. partial_correlation_analysis.py -- Парные и частные корреляции
Демонстрация разницы между парными и частными корреляциями.
Что реализовано:
- Генерация многомерных нормальных данных с заданной ковариационной матрицей
- Вычисление парных корреляций 
- Вычисление частных корреляций через обратную матрицу корреляций
- Регрессия X1 от остальных переменных
- Визуализация остатков
